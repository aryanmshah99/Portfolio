VideoForce CI

Give it one brand name. It finds the competitors, collects their video ads, watches them, and writes the report.

The pipeline · one command, end to end — nine stages in order. Four call the model and are covered by the shared retry and failover layer.

Every stage runs independently and imports cleanly. Stages are joined by a strict output/{brand}/ file scheme.

Multimodal orchestration

Gemini on Vertex AI, reached through Application Default Credentials, doing four distinct jobs. Video goes to the model via gs:// staging; image frames go inline as base64.

When things fail

One shared retry layer sits under every external dependency. A transient 503 or 429 climbs a ladder — timed retry, then failover across a prioritized model list, then a non-LLM fallback. Gemini, Foreplay, and SerpAPI all degrade instead of crashing.

Cost & latency

Classification calls batch to Vertex AI’s 10-video cap. Transcription runs in parallel. Per-item checkpointing means a cancelled run resumes rather than re-billing finished work — about 13 minutes back per run.
